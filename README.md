# Demo Project Data

This directory contains complete data for 4 DramaClaw demo projects. Copy the
contents to `/home/z/dramaclaw-data/` to serve them.

## Projects

| Project | Description | Episodes | Beats | Characters | Scenes | Props |
|---|---|---|---|---|---|---|
| `novel` | 钟楼偷时间的人 (The Clocktower That Stole Time) | 3 | 9 | 5 | 5 | 5 |
| `magi` | Gift of the Magi (O. Henry) | 1 | 4 | 3 | 4 | 5 |
| `starfarer` | 星港异变 (Starport Anomaly) | 3 | 9 | 5 | 3 | 8 |
| `xianxia` | 五行天骄 (Five Element Genius) | 3 | 30 | 5 | 5 | 6 |

## What's included

- `state/local/settings.db` — Gateway config (zai-gateway URL)
- `state/local/projects.db` — Project registry
- `state/local/{project}/data.db` — Per-project SQLite (characters, scenes, props, episodes, beats, canvas)
- `output/local/{project}/assets/` — Character portraits, scene masters, prop references
- `output/local/{project}/frames/` — Beat render frames
- `output/local/{project}/sketches/` — Beat sketches
- `output/local/{project}/audio/` — TTS narrations (MP3)
- `output/local/{project}/assets/narrator/` — Narrator voice samples

## What's excluded (regenerate via scripts)

- `**/videos/**/*.mp4` — Videos (regenerate via `examples/*-gen-assets.py`)
- `**/freezone/` — Canvas uploads/outputs (not essential for demo)
- `**/grids/` — Grid render/sketch images (generated by the grid system)
- Files > 2MB — Large AI-generated images (regenerate via image gen scripts)

## How to restore

```bash
# Copy demo data to the dramaclaw-data directory
cp -r demo-data/* /home/z/dramaclaw-data/

# Then run the bootstrap script to start services
./tools/dramaclaw-bootstrap.sh
```

## How to regenerate excluded assets

```bash
# Regenerate videos (requires zai-gateway running)
python3 examples/starfarer-gen-assets.py
python3 examples/magi-gen-assets.py

# For the novel project (钟楼偷时间的人), use the integration scripts:
cd /home/z/dramaclaw
.venv/bin/python integration/mock-gen-videos.py
```
